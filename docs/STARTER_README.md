# Fun

Portal de jogos multiplayer em `https://fun.kw1.com.br`. Primeiro jogo: **Sabe Essa?** (nome provisório).

## Começar

1. Leia `docs/PRODUCT_SPEC.md` (regras), `docs/ARCHITECTURE.md` (servidor/implantação) e `AGENTS.md` (instruções para Codex).
2. Cole ou anexe `prompts/CODEX_KICKOFF.md` à sua sessão do Codex aberta na pasta `Documents/github/Fun`.
3. A implantação deve reutilizar com segurança o servidor Termux existente e a rota Cloudflare `fun.kw1.com.br`.

**Situação inicial:** especificação e plano; ainda não há código implementado. Não comitar credenciais ou tokens.
